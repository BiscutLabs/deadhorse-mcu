# Recovery loader control verification

Run `python tools/env/run.py run -- python3 hw/ip/i2c_recovery_loader/formal/check.py --output build/t18/formal-new`. Use a fresh output directory. The runner emits the production controller with each harness, records every emitted source hash, checks the assertion or cover cell count and records the actual solver status and exit code. A cover or a rejected fault requires a concrete VCD witness. A timeout fails the gate.

| Role | Inputs and observations | Correct check | Real fault |
| --- | --- | --- | --- |
| Safety | Arbitrary complete or malformed frames, reset context, halt, memory ready/done and warm reset at the public control interface. A one-bit monitor remembers a syntactically valid WRITE to the observed next offset and consumes credit on a memory grant. | Unbounded temporal induction. Lock persists on every edge after acquisition until cold reset. A start pulse requires a validated image and an authorized start command. Each offered write requires credit, LOADING mode, an unlocked invalid image and the aligned in-range offset. | Use whole reset on the production lock register. A warm reset after LOCK+START erases the lock. |
| Accounting | A scripted four-byte image in the full 2048-byte program configuration. Choose either of two different words and one of four completion edges. CRC expectations come from Java CRC32. Send malformed and wrong-offset writes, stall the legitimate write, present early and duplicate completions, and assert SELECT on the matching completion. | Bounded to 90 service edges. Check the write data, offset, grant count, received-byte accounting, verification, start and retention across warm reset with later upload attempts. | Add four extra bytes to the production Stored count. |

The safety induction includes auxiliary **assertions** on the real byte count, accepted length and pending state. The count and length are aligned and ordered within capacity. Pending memory work requires room for the word and an unlocked, invalid image in LOADING mode. These statements must hold from reset and in the induction step along with the public properties. There are no harness assume cells or cutpoints.

The initial cold reset is asserted. Subsequent cold resets are unrestricted. The qualified whole-reset input is asserted for every cold reset and can assert independently for the warm causes. The harness models a single digital service clock and does not quantify analog pulse width or recovery/removal. Frames bypass the wire front end. Pin timing, wake detection, and SRAM implementation are outside this control proof.

The safety cover and mutation jobs drive the scripted upload on the real register and CRC logic. Covers require an actual memory grant, a validated locked start and a later warm reboot that preserves lock and invalidates the image. The accounting covers exercise both endpoint data choices and completion-delay extremes. Scripted bounds include the final locked upload attempt. Ordinary firmware, arbitrary multiword CRC correctness, physical timing and eventual completion under indefinite backpressure require separate evidence.
