# T40 DMA circular UART receive

## Outcome

Done under D102's scoped implementation/test policy on
`codex/t40-dma-circular-rx`, with the formal closure deferrals listed below.

## What changed

D102 is the existing authorization; no new design decision, endpoint or
non-circular behavior was introduced. T41 was first merged and pushed to
`main` as `10a142c` (reviewed T41 tip `f3a1e32`). T40 stays on its own branch.

- `hw/ip/dma/`: endpoint bit5 selects circular receive. Only validated UART
  RX selectors1/3/5 and counts at least2 are legal. Existing shadow registers
  supply reloads; active ring mode is captured at START. Busy circular shadow
  writes are ignored and set config-error, including the entire endpoint
  register. Original span, alignment, ownership and duplicate checks remain.
- Half bits19:16 and wrap bits23:20 are W1C, with matching IRQ enables.
  Half follows the successful item reaching floor(count/2); wrap follows
  actual reload. ABORT/fault suppress reload; successful half-item ABORT
  still reports half. Circular mode never reports done. No overrun/read
  pointer or second stored descriptor was added.
- Current publishes after successful RX POP, following SRAM commit. Running
  cursors are modulo positions; stopped ABORT may leave a one-past-end cursor.
  The driver checks channel status and uses an I/O-read-to-memory-read fence.
- `sw/hal/dma_ring.h`, its native tests and variable-length-frame example;
  `dv/soc/dma_circular*` and the production-core UART loopback suite.
- `formal/DmaCircularFormal.scala` checks the actual wrapper, arbitrary MMIO
  and arbitrary bus replies. Independent proof-only descriptor/lap state
  advances on successful POP and checks current, remaining and event pulses.
  No shadow stability, fairness or eventual-response assumption is added.
- README, formal ledger, STATUS and plan08 area arithmetic. Generated maps
  and emitted RTL stay under `build/`.

Test inventory: all five original `DmaEngineSpec` tests and both original
`SocDmaSpec` scenarios remain. Added six circular-engine cases, five MMIO
cases and one production-core case. The old SoC PWM scenario's assertion
that peripherals survive held AON reset was stale after T41: its unchanged
1500-of-2000 high-sample/repeated-period and invalid-duty/no-write oracles now
run with AON qualification present and only the fixture's memory client held.
A separate check removes qualification for the documented two AON plus two
main edges and verifies cancellation/disabled PWM/cleared DMA. No production
reset bypass or survival behavior was restored. No test was dropped.

## Deviations from the brief

Original finite-transfer proofs explicitly tie the newly added circular input
low to preserve their original input domain and assertions; the new actual
wrapper model checks circular mode, including its real shadow-write lock.
The inherited unbounded SRAM-range timeout was not rerun unchanged. New
bounded evidence and one capped triage round are labelled separately.

The focused SoC suite uses the existing named continuous-clock production
digital assembly with real cores, SRAM, fabrics, UART and DMA, and the allowed
USB stub. Oscillator/pad analog behavior is outside this UART receive test.

## Open issues

No hardware overrun detection is promised. Firmware must consume before an
entire unseen lap overwrites data; the driver cannot distinguish that from an
empty ring. Physical timing, scan insertion and whole-chip remapping remain
later physical-flow work. Formal results/debt follow the final receipt and
[DMA formal ledger](../../../ledger/dma-formal.md); bounded checks are not
unbounded proofs.

The step-0 model has2,354 cells,1,490 sequential bits and no RAM. Growth at
16/32 steps is3.722s/timeout121.261s; the32-step run last attempted index28,
which is not a discharged bound. Range/count arithmetic, MMIO/arbitration
and four-channel history share cones. The isolated reload-fault cone has
1,785 cells/923 state bits and reached attempted index30 before its cap.
Next proof work should partition per-channel conservation from shared bus
retirement, with independent review and new triage authorization. No
unproved helper may be assumed. No further attempt was made in this task.
