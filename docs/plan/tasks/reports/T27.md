# T27 Raw ADC acquisition and firmware conversion

## Outcome

Done for the user-approved D71 functional migration: production RTL, frozen
focused checks and independent review pass; CI and physical qualification
remain separate and unrun.

## What changed

- Recorded D71: retire hardware-scaled ADC register 0x14; every read/write,
  including zero-strobe writes, now errors. All other offsets remain.
- Production Adc selects the registered raw engine result. Removed scaled
  storage and scaler instantiation from the wrapper. Extracted existing
  raw/sequence/unread state into AdcSampleState for direct arbitrary-input
  proofs; sample arrival wins over ACK and event set wins over W1C.
- Updated only the retired-ABI expectations in AdcSpec/SocIoSpec, preserving
  wire, ownership, reset, command, continuous, IRQ and overrun checks. Added
  exact wire/MMIO ACK and event-clear collisions, publication faults and
  external-pin cadence measurement. Kept historical scaler assertions/faults.
- Supplied generic sw/hal/adc_convert.h and exhaustive native arithmetic
  oracle, compiled fault and both-core ABI link checks. Consumer inventory
  found only the two test benches reading the retired register; no handwritten
  firmware/HAL consumer required migration. Generated maps/headers are rebuilt.
- Updated block/SoC contracts, provenance, focused runners and ledgers. No
  vendor, other peripheral ABI, clock source or shared CDC implementation changed.
