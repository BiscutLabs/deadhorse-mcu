## Deviations from the brief

- Adapted the launcher/build conventions, not the upstream async library or
  handwritten SV testbench conventions. The task explicitly calls for direct
  Chisel dependencies and ChiselSim tests.
- Routine API/tool fixes: Chisel's Clock cannot be poked as Bool; an explicit
  Bool clock pin in the test harness permits edge-free reset testing through
  ports. String-returning stage APIs reject `--target-dir`; file emitters supply
  that option instead. Native BTOR2 needs `--lower-to-core` and immediate
  verification lowering. Yosys requires `async2sync` before lowering edge-triggered
  checks. BtorMC reports a separate result for each assertion; the parser now
  requires all property IDs, rather than accepting partial success.
- Formal checks cover sampled reset response and registered data, with initial
  reset and history-valid constraints documented in the
  [formal contract](../../../../hw/lib/formal/README.md). Native CIRCT BTOR2
  models reset in the next-state function; asynchronous assertion between edges
  is separately tested in simulation. No reset synchronizer or analog reset
  timing is claimed. No input-data or DUT-output assumptions were added.
- The general policy requests a ledger under `docs/ledger/`, outside T07's
  permitted changes. This report records the proof ledger, with the block
  contract and ignored receipts beside the verification evidence. No unrelated
  ledger or plan-policy file was changed.
- GF180 timing flow is T09, dependent on T07. This build fixture is not claimed
  to meet a physical timing budget.
