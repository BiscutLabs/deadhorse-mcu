## Numbers

### Timing blocker (measured, mapped pre-layout)

Full CI's registered no-F path runs from `controller_run_o` to `mcycle_counter_q[59]`:
25.335854 ns, 22 mapped cells/20 logic stages, area 455534.7328 um2, electrical violations 0.
Derived excess: 25.335854 - 24.960000 = **0.375854 ns (1.506%)**. The prior T11
`build/t11/csrfinal1/top_timing/result.json` measured 24.923273 ns with identical
mapping, tools and constraints; only emitted core/CSR sources differ. This identifies
a mapped timing regression, not a diagnosed functional defect.

Fresh F-integrated timing passes at **24.698816 ns**, area **875676.256 um2**
(`ci-fast-registered/fast/timing/result.json`); that does not clear the no-F failure.
Both use pinned GF180 7t5v0 SS/125C/3.0V, ideal pre-CTS clocks and the unchanged
24.96 ns allowance. Area is mapped cell area, not routed die area.
