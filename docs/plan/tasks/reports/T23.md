## What changed

- `hw/ip/dma`: four finite-count channels, packed UART/SPI byte transfers,
  checked PWM word updates, registered bus offers, transaction round robin,
  owner/range validation, abort/drain and partial-error semantics, generated
  register map, IRQ and clock demand.
- Optional `SocDmaFiles` / `EmitSocDma` profile binds real SRAM and peripheral
  fabrics, IRQ8, UART/SPI requests and PWM request/ack. The endpoint table is
  derived from register contracts; no arbitrary peripheral address or origin
  is software writable. Native SRAM arbitration adds an optional DMA port.
- Independent transaction/data model and fault tests; real SRAM/UART/SPI/PWM
  composition tests; idle-DMA comparison and contested memory tests; scoped
  formal harnesses/triage; GF180 screens and focused frozen runner. Prior
  profiles and unrelated local changes are preserved. No CI invocation.
