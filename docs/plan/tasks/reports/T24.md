# T24 Limited GPIO output pin mux

## Outcome

Done for the functional T24 pin mux and independently reviewed frozen checks; physical/SoC qualification and CI remain open.

## What changed

- Added `hw/ip/pinmux`: three registered pad selectors, reset-disconnected
  outputs, same-index GPIO/timer/PWM choices, disabled handover interval and
  registered clock retention through configuration propagation/handover.
- Generated owner-checked registers occupy 0x40012200 in the new opt-in
  `SocPinmuxFiles`/`EmitSocPinmux` profile. The profile extends functional DMA;
  prior profiles and dedicated pins stay unchanged. Raw GPIO input/IRQ/wake
  still observe their original pins.
- Added independent cycle-oracle tests, actual faulty RTL, three formal jobs,
  MMIO/pin/clock-demand/reset integration tests, real-core reset firmware,
  validated map metadata, preparation and focused frozen-check runners.
- Added block/formal contracts and ledger; updated top/SoC documentation,
  task brief/index and own progress entry. No vendor or existing peripheral-engine edit.

## Numbers

Measured by the frozen timing command above on the source-bound local snapshot,
GF180 7t5v0 SS/125C/3.0V, Yosys 0.71+34 e419c4eef and OpenSTA3.2.0.
Mapped pre-layout at the existing main-9MHz screen, conservative for the
8/9MHz profiles. Estimated budget: `0.60 * 1000 / 9 = 66.666667 ns`.
Assumed ideal clocks, zero boundary delay, 0.5ns input transition, 0.05pF output
load; no physical wires, pad delay or hold/reset-removal qualification.
