# T38 basic layout and fit study

## Outcome

Done for D112's basic placement/fit scope: the production chip fits the existing
core after placement and CTS; full T38 verification and physical signoff remain
deferred.

## What changed

- D112 records the user's decision to obtain basic layout/fit data before T37,
  and the follow-up to defer routing, DRC and production-GDS work.
- `docs/spec/t38-physical-measurement.md` defines the scoped result. The existing
  T43 production wrapper, pad map, SRAM inventory and analog footprints remain.
- `tools/physical/chip_prepare.py`, `chip_constraints.py`, `chip_power.py` and
  `chip.py` assemble authenticated production mapping, actual macro/pad views,
  exact clock/USB constraints and explicit physical stages.
- `chip_inspect.py` checks original circuit connections through inserted
  physical buffers and qualifies substitutions against all fifteen pinned
  Liberty views. `usb_cells.py` now handles a single CLKN pin while retaining
  the complete flip-flop clock/state semantics; focused faults remain.
- `chip_clock_audit.py` checks clock identities and exact USB exception pairs.
  `chip_fit.py` measures placed geometry and renders actual instance boxes.
- `chip_flow.py` contains independently reviewed preservation wrappers for
  subsequent physical optimization. They passed a focused callback test but
  were not needed by the completed cts02 run. `chip_timing.py` remains a
  diagnostic prototype: no successful post-CTS class measurement is claimed.
- No functional RTL, register map, pin assignment, memory size or vendor source
  changed. Generated layout/database/image files remain under `build/`.
