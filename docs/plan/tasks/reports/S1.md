register-reuse optimizations with a lower hard-float cycle count. This report

## Numbers

**Measured timing/area:** GF180MCU `gf180mcu_fd_sc_mcu7t5v0`, slow process,
125 C, 3.0 V, Yosys 0.71+34 and OpenSTA 3.2.0. Core, integer/float registers,
multicycle FPU and exposed word-wide byte-enable memory interfaces total
839962.5472 um2 of mapped standard cells (derived 0.839963 mm2). SRAM macros,
whole-chip interconnect, pads and physical placement are excluded.

The worst register-to-register path is 65.726219 ns, `_64411_/Q` to
`_62733_/D`, 73 logic stages. Input/register 29.244478 ns, register/output
47.568443 ns, input/output 25.166069 ns; clock-gate enable paths and electrical
checks pass. This is mapped, pre-layout screening with ideal clocks and no
wire delay. The unchanged 60% rule at 9 MHz permits 66.666667 ns, giving a
derived 0.940448 ns margin. ABC retains the existing 62500 ps mapping target.
It is not 12/24 MHz closure or routed signoff; 9 MHz remains a trial.

**Measured performance inputs:** fixed point retires 271663 instructions in
465575 cycles across the 120 exact loop windows; hard float retires 179342 in
1480640 cycles. The windows include input staging, the control call, checksum
and loop housekeeping. They exclude boot/setup, between-mode work and final
output. CPI is total cycles / total instructions; MIPS is
`9 * total instructions / total cycles`. Minimum per-iteration throughput is
5.196217 / 1.055311 MIPS respectively. No fitted average substitutes for the
observed worst cycle count in the deadline calculation.

**Measured arithmetic retirement spacing:** fixed-point MUL mean 3.003120,
worst 4 cycles (28845 samples); MULH and MULHU 4 cycles; DIVU 37 cycles
(45 samples). Hard-float MUL is 3 cycles, FMUL.S 41 cycles (9070 samples),
FDIV.S mean 60.777778/worst 61 cycles (45 samples). These include pipeline and
fetch effects and are not isolated unit latency. Signed DIV was not observed.

**Assumptions and exclusions:** existing independent instruction/data
acceptance, ideal one-cycle responses and a 4 MiB fixture address space.
This does not claim 16 KiB placement. S3's separate allocation evidence
remains separate. Sensor drivers, navigation, DMA/ownership contention,
XIP/logging interference, interrupt arrival during FPU execution, actual
SRAM latency and a complete firmware deadline remain unmeasured here.
The hard-float comparison observed zero interrupts and zero architectural
FCSR probes; it does not newly qualify flags or interrupt behavior.

## Deviations from the brief

The user authorized S1 despite deferred T13 formal acceptance and previously
authorized the named 9 MHz timing trial. No default production clock was
changed. The ideal baseline was measured first to avoid a larger sweep when
the selected core already misses the throughput floor. The explicit
below-2.5-MIPS rule stopped banking/latency and interrupt measurements before
they ran. No core replacement, F removal or optimization was attempted.

An unused banked responder draft created during this task was archived as
`build/s1/unused-drafts/s1_sim_main.cpp` (SHA-256
`7bd2a7a7b1b2cfa5bd8d76037287c46f850ce7cc59a2d4e431ba94c9a1f9f9d7`)
and removed from deliverables. The receipt's broad input snapshot includes
that draft, but the compiled simulator used unchanged `dv/core/sim_main.cpp`.
The draft was never compiled or used as evidence.
