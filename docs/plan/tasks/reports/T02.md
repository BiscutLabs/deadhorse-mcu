## Deviations from the brief

The user authorized LF normalization and routine tooling repairs without pausing. The first baseline launch failed on CRLF; an initial unbuffered trace run was stopped because per-instruction writes were slow across the Windows bind mount. Buffered capture preserves the deadline.

QEMU's finisher can exit before the named spin executes. The collector therefore requires either the first spin record immediately following the exit store, or a successful process exit whose last trace instruction is the explicitly named exit store. A missing marker on arbitrary EOF does not pass. The earlier attempted rvsim-only exit register was invalid on QEMU and was discarded; the QEMU finisher mapping is preserved. No simulator counting or tolerance changed.

The existing no-op loop is expressed with adjacent assembler labels inside the permitted C harness, avoiding an extra call counted only by QEMU. The headline grep correction and clean-source snapshot address pre-existing acceptance-command ambiguities without changing the measured workload. Local-only execution follows the user's decision; no hosted workflow was added.
