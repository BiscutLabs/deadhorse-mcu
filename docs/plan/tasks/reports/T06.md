## Deviations from the brief

Routine tooling repairs were authorized by the user; no source, test, deadline,
skip policy or tolerance was changed. Retained failures and recovery:

- Windows CRLF invocation failed with `set: pipefail: invalid option name`.
  Used an ignored LF-only bootstrap copy.
- An initial full attempt was interrupted during compilation because sbt ignored
  shell `SBT_OPTS` and cached under `/root`. Explicit JVM properties put caches
  under the repository; that attempt is not claimed as a passing run.
- A Python fixture failed with
  `ERROR: test_only_fresh_nonempty_successful_suites_count_as_execution (test_ci.CiTest.test_only_fresh_nonempty_successful_suites_count_as_execution)` and
  `ValueError: CI_MISSING_FRESH_SUITE:riscay.Chip`, ending
  `FAILED (errors=1, skipped=1)` before Scala ran. Native Linux tmpfs removed
  the Windows bind-mount timestamp problem; the unchanged test and full gate
  subsequently passed. The probe established timestamp disagreement, not the
  exact stale offset. The failed receipt is preserved.
- The historical mapper initially failed before synthesis with
  `ModuleNotFoundError: No module named 'encodings'`. Recovered the exact
  historical Yosys/ABC binaries and matching runtime closure from the supplied
  workspace, copied them into repository-local ignored storage, and executed
  them inside T08. The failed mapping receipt remains preserved.
- Archived the entire first checkout and reran the gates in a fresh clone,
  retaining tool caches. Failed receipts were neither deleted nor filtered from
  the acceptance glob. Archive prefix remapping is explicit in the ledger.
- A preliminary clean-tree local gate caught the not-yet-written report link:
  `REL_LINKS docs/ledger/riscay-baseline.md: missing target ../plan/tasks/reports/T06.md`.
  Completing this report supplies that target without changing the check.
- The verification snapshot initially lost executable permissions during file
  copying, causing `./run_all.sh: Permission denied`. Restoring the recorded Git
  executable modes in that ignored snapshot allowed its unchanged local gate
  to pass. The actual merged worktree gate also passed independently.
