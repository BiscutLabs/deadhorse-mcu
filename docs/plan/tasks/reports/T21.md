# T21 GPIO, split timers and retained ADC

## Outcome

Done for the functional T21 implementation and independently verified focused checks; CI and physical SoC qualification remain open.

## What changed

- D68 records the user-approved split: AON sleep deadlines remain at 0x40000000;
  main microsecond capture/compare lives at 0x40012100. Decision, STATUS and
  peripheral contracts updated. Work remains on main.
- New generated-map Chisel GPIO, main timers, AON timers and adopted ADC IP.
  GPIO has registered pad control, edge IRQ and acknowledged AON level wake.
  Main timers have modulo timestamp, four capture/compare channels and separate
  IMU capture. AON timers remain usable with main stopped. ADC preserves pinned
  wire framing, first discard and exact iterative scaling, with MMIO/ownership.
- `SocIoConfig`/`EmitSocIo` select actual functional bindings. Shared CDC handles
  all crossings. IRQ9/11/12, AON IRQ/wake, clock demand and SPI timestamp wiring
  are explicit. Nested GPIO/timer decode reuses the drain contract and keeps
  the outer timeout. I1's stub profile and original tests remain intact.
- `soc.yaml` child windows are validated and emitted into firmware/Scala maps.
  New focused block/SoC tests, formal harnesses, receipt runners and conservative
  GF180 screens; no vendor edits, new CDC primitive or pad-ring implementation.
- GPIO reset-release fanout is repaired only in mapped output, with the existing
  verified non-inverting buffer pass. Every original pin/clock is checked;
  a deliberately cyclic buffer must be rejected. No RTL storage/reset change.

## Deviations from the brief

No CI by explicit user instruction; neither fast nor full tier ran. No changes
to pre-existing assertions, limits, assumptions or bus timeout. Formal claims
are deliberately scoped: timer update consistency is not an independent full
cadence/wake-delivery proof; ADC scaling is bounded to 16 edges for one symbolic
sample. Directed tests supplement these properties. No whole-chip timing claim.
