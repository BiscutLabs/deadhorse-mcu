# T34 Analog interfaces and behavioral models

## Outcome

Done with D87 verification exceptions: analog interfaces/models, scoped digital
acceptance and characterization handoff are complete; physical qualification
and inherited composition debt remain open.

## What changed

- D87 records the user-approved T34 exception: only relevant checks, no
  aggregate CI, defer extensive timeout proof work without weakening claims.
- `analog/lf_rc/README.md` and `analog/por_brownout/README.md` define every
  physical/model pin, defaults, reserved controls, diagnostic outputs and
  calibration/test-access limits. `analog/characterization.md` defines the
  provenance, PVT/mismatch/noise/latency matrix and later physical handoff.
- Existing LF/POR simulation models expose inert trim/test inputs matching
  production ties. Production macro pins and clock/reset policy are unchanged.
- `AnalogContractSpec.scala` adds independent timeline and fault tests;
  `dv/soc/analog/check.py` runs only selected analog/model/production-reset
  checks with source/tool/artifact hashes. `binding.py` audits emitted
  production connections and deliberate pin faults.
