## Deviations from the brief

No CI by user instruction. The pinned RISCay baseline has GPIO-bit-banged flash,
not a QSPI controller, so this is new clocked Chisel using existing qualified
primitives, without vendor imports. Existing formal caps and all inherited
checks remain unchanged. Engine proofs cover safety; completion and dynamic
ownership are independently checked simulations with negative controls.

## Open issues

- No further RTL blocker was identified within the command-only scope.

  throughput remain unimplemented by this command-only subset.
- Flash part/opcode configuration, dummy-phase pull-ups, pad/board sampling,
  physical reset/RDC/hold and whole-SoC timing/area require qualification.
- Controller reset cannot cancel a flash-internal program/erase already accepted.
