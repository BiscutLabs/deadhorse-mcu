## Outcome

Blocked on full-width watchdog formal closure; D70 RTL, functional checks,
output-disable proofs and corrected mapped setup/electrical screens pass.
Independent review cleared this scoped, incomplete checkpoint.

## What changed

- Recorded user decision D70 and its plan06 reset-scope clarification.
- Added `hw/ip/watchdog`: pinned clocked count/hold adoption, generated
  owner-checked MMIO, immutable active settings, windowed feed, advisory
  warning, POR-retained cause/count and reset hold, tests and formal jobs.
- Added optional PWM output-disable acknowledgment and split pinmux output
  banks. The watchdog profile requires STOP then APPLY after reset. DMA
  cannot clear the break. The actual memory epoch-drained signal prevents a
  pre-reset retained STOP from acknowledging a post-reset break.
- Added `EmitSocWatchdog`, validated subwindows, real NMI/shared-reset wiring,
  loader cause/count binding and AON demand. Performance expiry resets the
  core/client epoch and PWM execution; shared services survive. Lite expiry
  resets ordinary whole-MCU state. Earlier profiles retain their behavior.
- Added block, MMIO, real-DMA continuation, retained-request and real-core
  firmware tests plus focused preparation/check scripts. No clock-source
  choice, physical clock gating or production boot change.
