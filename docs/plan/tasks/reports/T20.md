  with preparation/execution distinguished and source/artifact receipt hashes.

## Numbers

The map check above **measured** nineteen configured region descriptions;
the focused unit command **measured** seven passing test methods, including
configuration fault controls. These are tooling results, not hardware results.
Clock frequencies, model latency, address subdivisions and logical pin groups
are **assumed provisional configuration**. SRAM capacities are existing
requirements. Estimated SPI limits and their arithmetic are in the contract.
No new SoC area, timing, instruction count or physical fit is claimed.

The focused simulation command measures twelve memory test cases and one boot
test. Configurations exercised include bank counts one/four and read latencies
one/three; these are test parameters, not measured SRAM macro timing. The UART
oracle assumes sixteen main-clock edges per bit for the firmware configuration.
The local-memory control proof uses the full production geometry, four banks
and one-edge reads. It discharges eleven assertions with ABC PDR, without a
finite proof-depth claim. Three covers and the actual response-valid fault use
SMTBMC/Z3 with a 32-step bound and 120-second job cap. Exact measured times and
source hashes are in the final receipt. This proves control only, not RAM data,
eventual MMIO completion, subcycle reset effects or all latency settings.

Final formal command measured whole-job wall times: covers 1.67 s, fault
0.42 s and unbounded safety 0.47 s (including model preparation). Covers reached
steps 5, 6 and 9; the injected fault failed at step 2. The combined simulation
command measured 13 passing cases in 78 s of ScalaTest execution. These are
verification runtime figures, not hardware performance measurements.

## Deviations from the brief

None accepted. The brief's required gateway-based target interface has no
production gateway RTL to bind today. The user has been asked whether to use
an explicitly simulation-only adapter or expand production gateway scope;
neither choice has been assumed. Focused direct-pin I0 tests proceed without it
and do not replace the required gateway/target-interface acceptance.
The initial map does not yet encode fabric hierarchy or complete pin allocation.
