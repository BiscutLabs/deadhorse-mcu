## Deviations from the brief

The original brief prohibited core changes. After the first timing failure
and independent reproduction, the user explicitly approved extending T09 to
repair RegBlock while preserving behavior and all checks. Only the relevant
decode/read-data structure and its documentation changed; no budget, library,
mapping recipe, interface, latency, fixture, reference model or assertion was
relaxed. The first local-write-only repair still failed at 25.511124 ns; the
complete repair passes. Earlier failed evidence remains in the ledger.

Routine development fixes included slang path quoting and sbt source-path
resolution. Independent review caught omission of launch clock-to-Q from the
initial path calculation; corrected extraction includes it. The real SRAM
negative control exposed empty synthesis stubs disappearing under optimization;
elaboration now rejects uncharacterized macros before mapping.
