## What changed

- `phys/gf180-ws-1x1/template.lock.json`, LICENSE and authenticated materializer
  pin official upstream collateral and all Nix dependency revisions/hashes.
  Selected source files are materialized under build, as for existing SRAM IP;
  no generated GDS or emitted RTL is committed. Local socket and simulation
  adaptations are recorded in `patches/README.md` and preparation receipts.
- `pdk-candidate.lock.json` preserves comparison inputs; active `pdk-lock.json`
  and `block-timing.json` select the new revision in a separate staged directory.
  Production RTL and SRAM views remain unchanged. Active library readers,
  fetch scripts, physical-view locks and timing skill now use the selected PDK.
- `tools/pdk.py` and `tools/physical/pdk_views.py` authenticate library/model/
  physical views and prepared inputs. USB library rebinding requires identical
  complete Liberty tokens and cell bodies, preserves original map/certificate
  identities and retains the current production source-binding check.
- `pad-map.yaml` and checker cover all production functions and mux aliases.
  `chip_core.sv` binds the production SoC to the canonical template socket;
  `chip_pad_feedback.sv` implements approved D110 local feedback and mutually
  exclusive IE/OE. Existing peripheral core-port tests remain unchanged.
- `prepare_chip.py`, `check_chip.py` and `dv/pad_*` authenticate the production
  elaboration and named analog-model boot fixture. No analog model replaces a
  physical macro in production. `sram-placement.yaml` and `prepare_sram_pdn.py`
  prepare the actual sixteen main and four retained macros, with geometric
  negative controls; this is not completed physical placement.
- `tools/check_structure.py` recognizes only the two authored physical SV
  files authorized by D105/T43. Focused fixtures still reject neighboring and
  nested SV files; no general RTL-location exception is introduced.
- `compare_pdk.py` records source/helper/netlist/input hashes and compares
  Liberty cells, tokenized whole files, LEF macros and production SRAM views.
  Missing corners and used definitions are checked; focused negative fixtures
  exercise these guards and token-boundary preservation.
- `docs/spec/t43-physical-base-proposal.md` presents independently reviewed
  common-supply pad and current-capacity SRAM recommendations.
