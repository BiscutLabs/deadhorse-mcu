# T13: 12 MHz timing trial

## Outcome

The user-authorized 12 MHz mapped timing trial passes for registered no-F and F-integrated cores; this does not close full T13 acceptance or adopt a new global clock default.

## What changed

- `tools/timing/check.py` and the core timing entry point accept the explicit `main-12mhz` operating point. OpenSTA uses a 1000/12 ns period; the existing 60 percent rule gives a 50 ns allowance, which ABC uses as its 50000 ps mapping target.
- Trial receipts are labelled `operating-point-trial`. Default CI and the physical configuration remain at 41.6 ns / 24.96 ns. Unknown operating points and trial selection for the default self-test are rejected.
- Corner, library hash, slew/load, IO constraints, electrical rejection, source isolation and clock-gate checks are unchanged. No RTL or vendored source is edited.
- The timing README, ledger and T13 status/report record the experiment separately from the previous failed full run.

## Numbers

Measured with pinned Yosys 0.71+34 (`e419c4eef`) and OpenSTA 3.2.0,
GF180 `gf180mcu_fd_sc_mcu7t5v0`, SS/125C/3.0V. Mapped, pre-layout,
ideal pre-CTS clocks; no wire parasitics, placement or SRAM timing.

| Profile | Measured worst path | Derived allowance margin | Measured cell area |
| --- | ---: | ---: | ---: |
| Registered no-F | 27.500998 ns | 50 - 27.500998 = 22.499002 ns | 453539.296 um2 |
| F-integrated | 30.671665 ns | 50 - 30.671665 = 19.328335 ns | 872504.192 um2 |

Both have zero electrical violations and minimum clock-gate setup/hold slack
0.704980 ns. These are fresh mappings at the slower target, not a same-netlist
slack comparison. The original 24 MHz failure is not relabelled passing.

Throughput is derived from the previously measured unchanged-RTL cycle counts
(`dv/core/performance.py`, receipts under `build/t13/feedback/performance`).
No new cycle simulation was needed because emitted RTL is byte-identical.
At 12 MHz, time in microseconds = measured cycles / 12:

| Profile / workload | Previously measured worst cycles | Derived worst time |
| --- | ---: | ---: |
| Registered no-F / fixed | 29350 | 2445.833 us |
| F-integrated / fixed | 32006 | 2667.167 us |
| F-integrated / hard float | 23509 | 1959.083 us |

The hard-float fixture misses a 1 ms deadline. A 2 ms (500 Hz) deadline leaves
only 491 cycles / 40.917 us before adding interrupts, external I/O delays and
real memory behavior. Neither system-level 1 kHz nor 500 Hz feasibility is established.

## Deviations from the brief

The user's explicit 12 MHz trial authorizes this named period change despite the
standing rule against silently relaxing timing constraints. The margin fraction
and all other checks stay intact; this is not a waiver or a global clock adoption.
